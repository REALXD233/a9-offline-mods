# A9 离线 Mod 管理器

[下载公开测试版](https://github.com/REALXD233/a9-offline-mods/releases/tag/v0.2.0-alpha.1) · [在线目录](https://raw.githubusercontent.com/REALXD233/a9-offline-mods/main/catalog/index.json)

Windows 便携管理器，可以按组下载、组合安装、独立卸载已有的 A9 离线 Mod。无需另装 Python。**0.2 为公开测试版，新的模块组合仍需玩家实际进游戏验收。**

| 可选组 | 内容 |
| --- | --- |
| 生涯快速重开 | 暂停菜单中的重新开始按钮及其界面适配 |
| fastest car | 1003，六星满改测试配置；性能分 6767，面板不代表官方评级 |
| 国服四车＋氮气功能 | F5R 5018、Jesko Absolut 5002、Tourbillon 5021、Silver Lightning 5009；包含现有氮气选择入口和已验收的兼容效果 |
| ALU 两车 | Jesko Absolut 294、IMPERIUM 345；保留 ALU 模型、兼容碳纤维材质和修正后的尾焰方向 |

公共核心自动下载，界面只显示上述四组。快速重开和 fastest car 的 ZIP 很小：它们启用公共核心中已有的功能或游戏原有的模型资源，并非空包。全部模块合计约 112 MiB，不需要下载多份完整资源包。

## 支持范围

目前只接受已登记的 **Windows 国际服离线 4.7.0d 整合版 r200、r203、r206**。管理器会同时核对主程序及 11 项公共文件的 SHA256。版本名相同而文件不同，也会停止接管。

本下载不含完整游戏、Steam 账号或个人存档。它不能安装到当前在线版 ALU、Xbox 版、安卓国服、未知修改版或普通纯净底包。较早分享包的用户如果提示基线不匹配，请导出检查报告；不要强行复制覆盖。

## 使用

1. 下载 `A9-Mod-Manager-0.2.0-alpha.1.zip`，完整解压到可写文件夹，再运行 `A9ModManager.exe`。不要在压缩包内运行。
2. 点“刷新在线目录”，在“保留”列勾选需要的组，点“下载所勾选”。首次默认四组全选；可以自行取消。
3. 选择包含 `Asphalt9_emu.exe`、资源包和 `a9emu` 的离线游戏根目录，点“预览四组选择”，检查版本、车辆和空间。
4. 完全关闭游戏及离线服务端，点“应用四组选择”。完成后手动启动服务端和游戏验收。
5. 卸载某组时，取消该组勾选并重新应用；也可选中该行，点“卸载所选”。其他组会一起按当前勾选状态保留。

GitHub 无法连接时可从 Release 分别取得需要的 `.a9mod.zip` 和公共核心，通过“导入本地包”导入。也提供含全部五个模块的 `A9-Mod-Manager-0.2.0-alpha.1-Offline.zip`，解压即可离线载入四组。

## 安装、存档和恢复

- 下载支持断点续传，安装前会核对大小、SHA256、模块身份、依赖及资源冲突。下载完成不等于已经安装。
- 第一次接管保留一套公共文件基础副本；组合从该副本重建，不反复叠补丁。暂存输出和恢复副本仍需数 GiB 空间，具体以预览为准。安装期间不要移动目录、退出程序或另用工具改文件。
- 管理器不读取或回滚个人存档。服务端会按启用组提供车辆；已取得的车辆进度在存档中保留，重新启用后继续使用。
- “撤销最近变更”恢复上一组选择。“恢复中断操作”处理已登记的中断事务；遇到外部文件变化会停止，保留现场。
- “恢复 / 空间 → 撤回到接管前整合版”恢复首次接管前的公共文件。原来整合版已有的车辆和功能也会回来，**这不是恢复纯净原版**。
- 完全撤回后，可以清理已登记的恢复副本；仍启用模块、发现文件漂移或存在未登记对象时会拒绝清理。不要手动删除游戏里的 `.a9mod-manager`。
- 保留管理器文件夹和导入的 ZIP 路径，卸载、撤销时仍需读取剩余模块。下载缓存位于管理器旁的 `ManagerData`；游戏资源基础副本位于游戏目录的 `.a9mod-manager`。

## 已知限制

本版从 r203 稳定资源构建，不收录 r204—206 未通过验收的氮气动画实验。国服 Absolut 的原始尾焰摆动没有完整恢复；Silver Lightning 使用已验收的兼容尾焰，未还原国服矩形电流图案。氮气页面持续预览问题保留。ALU 两车未宣称复刻新版引擎物理；重生外壳修正仍待人工验收。

已验证真实模块的 16 种数据组合、完整四包生成、旧 GIN 升级结果、隔离安装与卸载、回滚、下载失败与续传。**这些检查不等于 16 种组合都已实机通过。** SHA256 用于完整性校验，目前没有独立的发布者数字签名；请使用本仓库的目录和发布文件。

出错时点“导出检查报告”，提供第一条错误文字及该 JSON。报告包含公共资源路径和摘要，不包含存档内容；分享前可检查路径是否需要遮盖。

## 开发

源码在 `source/`。运行需要 Python 3.12 和 Tk；只有截图检查需要 Pillow。Windows 构建使用 PyInstaller 6.22.3：

```powershell
python source/app.py --demo
python source/app.py --self-test --out tests.json
python source/check_ui_workflow.py ui-tests.json
python -m PyInstaller --noconfirm --onefile --windowed --name A9ModManager --paths source --paths source/vendor --distpath out --workpath build --specpath build source/app.py
```

模块配方由固定的管理器代码处理，不执行 ZIP 中的 Python、PowerShell 或其他安装脚本。配方格式见 [FORMAT.md](FORMAT.md)。源代码仓库只放管理器、文档和目录；模块材料作为 Release 附件发布。项目尚未声明整体开源许可；第三方运行库的许可证随管理器附带，游戏素材的权利归各自权利人。
